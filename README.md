# Учёт расходов

## Что делает программа

Консольный учёт расходов. Можно добавлять траты (категория, сумма), смотреть отчёт и считать сумму по каждой категории, общий итог и категорию, на которую потрачено больше всего.

## Как запустить

Нужен Python 3. Команда запуска:

```
python main.py
```

## Проверка 1

- Вход: пункт 1, категория «еда», сумма 250, затем пункт 1, категория «транспорт», сумма 60, затем пункт 2
- Ожидание: обе траты добавлены, в отчёте две категории, общий итог 310
- Результат: всё работает как ожидалось, итого 310.0, больше всего потрачено на еду

## Проверка 2

- Вход: пункт 1, категория «еда», в сумму введены буквы
- Ожидание: сообщение об ошибке, программа не падает и возвращается в меню
- Результат: показано «Ошибка: нужна категория и положительная сумма.», трата не добавлена, меню работает дальше

## Паспорт разработчика

- **Псевдоним:** Луговая Надежда
- **Название артефакта:** Учёт расходов
- **Что он делает:** хранит список трат, считает сумму по каждой категории и общий итог, показывает самую затратную категорию
